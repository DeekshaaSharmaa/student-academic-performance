## 📌 About the Project

Student Academic Performance Analysis is a data analytics project focused on understanding students' academic performance using marks, attendance, and study habits.

The project aims to identify patterns in student performance, compare subject-wise results, and explore how attendance and study hours are associated with academic marks.

Through data analysis and visualization, this project presents meaningful insights that can help educators better understand students' academic progress.

## 🎯 Project Objectives

- Analyze students' academic performance across different subjects.
- Calculate average marks and pass percentages.
- Study attendance patterns.
- Explore the relationship between study hours and academic performance.
- Create meaningful charts and visualizations.
- Present important findings through an interactive dashboard.

## 📊 Key Project Features

- **Data Cleaning:** Checking missing values and duplicate records.
- **Descriptive Statistics:** Calculating mean, median, and other statistical measures.
- **Subject-wise Analysis:** Comparing average marks across subjects.
- **Pass Percentage:** Understanding overall student results.
- **Attendance Analysis:** Exploring attendance and academic performance patterns.
- **Study Habit Analysis:** Exploring the association between study hours and marks.
- **Interactive Dashboard:** Displaying key statistics and visualizations.

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_LINK
```

### 2. Open the Project Folder

```bash
cd Student-Academic-Performance
```

### 3. Install Required Libraries

```bash
python -m pip install streamlit pandas matplotlib seaborn
```

### 4. Run the Dashboard

```bash
python -m streamlit run app.py
```

The dashboard will open in your web browser.
